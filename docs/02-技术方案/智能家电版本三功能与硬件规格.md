## 1. 系统定位

本系统是基于 STM32F103C8T6 的智能家居控制与环境监测原型，具备本地检测、OLED 显示、按键控制、APP 控制、阈值自动控制、门锁鉴权和机智云远程控制能力。

系统执行器包括：

- 风扇；
- LED 灯；
- 28BYJ 窗户机构；
- 舵机门锁装置；
- 蜂鸣器。

系统不包含水泵、独立火焰传感器和人体存在传感器；不包含光照传感器。

## 2. 检测功能

| 检测项目 | 数据类型 | 主要用途 |
|---|---|---|
| 温度 | 数值 | OLED 显示、温度超限自动开启风扇 |
| 湿度 | 数值 | OLED 显示、环境状态监测和阈值调节 |
| 烟雾浓度 | 模拟量或换算值 | OLED 显示、通风和报警 |

烟雾传感器用于实验演示时，应明确其为模拟烟雾检测，不能表述为消防认证设备。不得把烟雾读数描述为火焰检测。

## 3. 显示功能

OLED 至少显示：

- 温度；
- 湿度；
- 烟雾浓度；
- 当前工作模式；
- 风扇、LED、窗户机构和蜂鸣器状态；
- 门锁状态；
- 报警状态；
- Wi-Fi 或机智云连接状态。

## 4. 手动模式

手动模式支持通过 STM32 按键或手机 APP 控制：

- 风扇；
- LED；
- 28BYJ 窗户机构；
- 舵机门锁；

手动模式下系统仍持续采集和显示传感器数据。普通设备由用户指令控制，自动规则不主动覆盖用户操作。门锁动作不受模式放宽，必须经过密码、IC 卡或 APP 授权。

## 5. 自动模式

自动模式由 STM32 本地状态机根据传感器数据执行固定规则：

| 触发条件 | 自动动作 | 报警 |
|---|---|---|
| 温度高于温度阈值上限 | 开启风扇降温 | 开启蜂鸣器 |
| 烟雾浓度高于烟雾阈值上限 | 开启风扇通风 | 开启蜂鸣器 |

自动模式要求：

- 连续采样确认后再执行动作，避免传感器瞬时抖动；
- 记录报警来源、当前值、阈值、时间和执行结果；
- 异常或离线传感器不能被当作正常读数；
- 自动动作必须经过固定设备服务和设备回执；
- 后端 Agent 不直接操作 GPIO、寄存器或任意云平台数据点。

手动模式和自动模式是互斥的设备主控制模式。APP 在两种模式下都可以查看数据、查看报警和切换模式；APP 是否允许在自动模式下临时强制控制普通设备，需在远程控制协议中单独确定。

## 6. 阈值调节

系统支持通过按键或 APP 调节传感器阈值：

- 温度阈值上限；
- 湿度阈值上限；
- 烟雾浓度阈值上限。

所有可调阈值必须经过范围校验，并在修改后同步到 OLED、APP 和本地控制逻辑。

## 7. 门锁与开锁

系统支持三种开锁方式：

1. 密码开锁；
2. IC 卡开锁；
3. APP 授权开锁。

门锁要求：

- 密码必须校验成功；
- IC 卡必须经过合法性校验；
- APP 开锁必须经过身份认证和授权；
- 开锁、关锁、鉴权失败和异常状态都需要记录；
- 门锁只能通过专用门锁接口控制；
- 通用设备开关接口不得控制门锁。

## 8. 云平台与远程控制

STM32 通过 ESP8266 Wi-Fi 模块连接网络并接入机智云平台。

```text
传感器 / 按键 / 门锁鉴权模块
             ↓
      STM32F103C8T6
             ↓ UART
        ESP8266 Wi-Fi
             ↓
          机智云
             ↓
          手机 APP
```

APP 支持：

- 查看温度、湿度和烟雾状态；
- 查看风扇、LED、窗户机构、蜂鸣器和门锁状态；
- 远程控制风扇、LED 和窗户机构；
- 进行 APP 授权开锁；
- 切换手动/自动模式；
- 调节合法阈值；
- 查看报警信息和执行结果。

机智云数据点必须通过受控适配器映射为内部固定设备命令和状态，不能把任意 Topic、GPIO 或底层数据点暴露给 Agent。

## 9. 控制架构

### 9.1 本地控制链路

```text
传感器 / 按键 / 密码模块 / IC 卡模块
                 ↓
       STM32F103C8T6 状态机
                 ↓
OLED / 蜂鸣器 / 风扇 / LED / 28BYJ 窗户机构 / 舵机门锁
```

### 9.2 云端控制链路

```text
APP 或自然语言请求
        ↓
固定设备工具与鉴权服务
        ↓
DeviceService / 受控协议适配器
        ↓
机智云数据点
        ↓
ESP8266
        ↓ UART
STM32F103C8T6
```

## 10. 主要硬件

| 硬件 | 系统职责 | 待确认内容 |
|---|---|---|
| STM32F103C8T6 | 主控、采集、状态机和执行控制 | GPIO、ADC、定时器、UART 资源 |
| OLED | 本地数据显示 | I2C/SPI 接口和地址 |
| 温湿度传感器 | 温度、湿度采集 | 具体型号、采样周期和时序 |
| 烟雾传感器 | 烟雾模拟量采集 | 预热、ADC 分压和阈值标定 |
| ESP8266 | Wi-Fi 和机智云通信 | AT 固件、UART 参数和数据点协议 |
| LED | 照明执行器 | 驱动电路和供电 |
| 5V 风扇 | 降温、通风执行器 | MOSFET/继电器和独立供电 |
| 28BYJ 步进电机及窗户机构 | 窗户开合执行器 | 驱动板、行程和限位反馈 |
| 舵机 | 门锁执行器 | PWM 参数和锁状态反馈 |
| 有源蜂鸣器 | 报警输出 | GPIO 电平和驱动电流 |
| 密码输入模块 | 密码开锁 | 输入方式和密码存储策略 |
| IC 卡模块 | IC 卡开锁 | 通信接口、卡号管理和授权策略 |

ESP32 原型目录可以保留为历史协议参考，但不属于版本三正式主控或通信基线。

## 11. 安全边界

- 所有设备控制必须经过固定工具、设备类型、在线状态、命令状态、TTL 和回执校验；
- 门锁必须使用专用接口并完成授权校验；
- 不向模型暴露 GPIO、寄存器、任意 Topic 或机智云底层数据点；
- 模拟适配器用于本地开发，真实联调前必须显式切换到受控协议适配器；
- LED、风扇、28BYJ 窗户机构和舵机均使用低压供电，不接入 220V 市电；
- 云端返回“命令已发送”不能等同于“设备已执行”，必须以设备回执为准。

## 12. 待确认事项

1. 温湿度和烟雾传感器的具体型号；
2. OLED 使用 I2C 还是 SPI；
3. 烟雾传感器输出是否需要分压后接 STM32 ADC；
4. ESP8266 固件方式、UART 参数和机智云数据点；
5. APP 在自动模式下是否允许临时强制控制普通设备；
6. 自动动作的连续确认次数、恢复条件和滞回范围；
7. 密码输入模块和 IC 卡模块的接口、授权数据保存位置；
8. 舵机门锁的 PWM 参数、锁止角度和状态反馈；
9. 28BYJ 窗户机构的行程、限位反馈和驱动板接线。
