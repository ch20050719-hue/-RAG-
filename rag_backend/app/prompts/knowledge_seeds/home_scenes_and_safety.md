# 智能家居场景与安全规则（种子知识）

## 场景规则

### 睡眠模式（sleep）
- 关闭 desk_light、desk_fan
- 目标：安静、低功耗、可安全恢复
- 执行后向用户汇报每台设备回执

### 离家模式（away）
- 关闭 desk_light、desk_fan
- 不自动开启任何设备

### 影院模式（movie）
- 关闭 desk_fan（保持安静）
- 灯光默认保持用户当前设置，除非用户明确要求调暗

## 环境舒适建议（非强制）

| 条件 | 建议 |
|---|---|
| 温度 > 28°C 且有人 | 建议开启风扇 |
| 温度 < 18°C | 建议关闭风扇并提醒保暖 |
| 光照 < 50 lux 且有人 | 建议开启台灯 |
| 无人（motion=0）超过场景设定 | 建议执行离家节能 |

建议必须经用户确认或由明确指令触发后才执行设备控制，不得仅凭模型猜测自动高风险动作。

## 安全红线

1. 禁止输出 MQTT Topic、GPIO 编号或原始指令
2. 禁止控制未注册设备
3. 禁止在设备离线时声称“已打开/已关闭”
4. 禁止接受任意自定义动作名
5. 命令必须携带 request_id 并等待回执
