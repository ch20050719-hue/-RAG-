# 智能家居前端说明

## 1. 页面与边界

前端提供自然语言对话和设备控制台。控制台只调用 `/api/v1/home`，不直连 MQTT、机智云、GPIO 或 STM32。

| 页面 | 路由 | 用途 |
|---|---|---|
| 智能家居主 Agent | `/`、`/multi-agent` | 查询环境、设备和安全规则 |
| 设备控制台 | `/home-devices` | 展示五类传感器、报警、趋势、设备和门锁 |
| 知识库/检索 | `/knowledge`、`/search` | 管理和检索设备说明与控制规则 |

## 2. 控制台当前功能

`src/views/HomeDevicesView.vue` 当前包含：

- 温度、湿度、烟雾、火焰、有人五类数据卡片和最近 10 分钟趋势；
- 手动/自动设备主控制模式切换；
- LED、风扇、喷淋水泵和蜂鸣器设备控制；
- 门锁状态、自动开门/关门、锁门、解锁和反锁操作；
- 应用内报警及设备在线状态轮询。

手动/自动模式与正常、睡眠、离家场景预设分层。模式切换不会隐式触发场景或门锁动作；场景按钮会显示逐动作回执。场景下可见的控制项按矩阵展示，但最终允许性由后端 `scene_policy.py` 强制校验。

## 3. API 客户端

实现位置：`financial_rag/rag_frontend/src/api/home.ts`。

```text
GET  /api/v1/home/devices
POST /api/v1/home/devices/{device_id}/state
POST /api/v1/home/pump/state
POST /api/v1/home/buzzer/state
GET  /api/v1/home/environment?room=study
GET  /api/v1/home/environment/history?room=study&minutes=10
GET  /api/v1/home/alerts?room=study&active_only=true
GET/POST /api/v1/home/automation-mode
GET/POST /api/v1/home/thresholds
GET/POST /api/v1/home/door/*、/lock/*
```

前端只提交固定设备标识和 `on/off` 状态。后端负责注册、类型、在线、过期、ack、幂等和门锁安全校验；只有收到可接受回执才显示成功。

## 4. 仍待硬件 UI 接入

密码、IC 卡和 OLED/按键属于 STM32 与硬件阶段。APP 的认证页面和云端数据点仍需在机智云产品、认证协议和真实固件确认后接入，不在前端假造硬件已完成。
