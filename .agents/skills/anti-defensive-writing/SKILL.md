# 论文自然改写与反防御性写作

围绕实际研究问题、完成的工作和证据组织论文，用清楚、自然的语言说明价值。根据用户指定的修改范围和认可样段执行，兼顾专业准确、段落衔接与完整性。

## 一、确定修改依据

- 优先读取用户指定的初稿、已认可的改写样段及相关资料。样段可以是先前确认的修改结果，不把它误称为用户亲自撰写的文字。
- 区分沿用的基础工作、本文新增内容、已有验证及待补结果。引用他人论文或已有系统时，保留相应归属，不能把他人成果改写成本人完成。
- 普通语言润色以已核实的稿件事实为基础；需要纠正技术描述时，查阅相关代码、图纸或记录后再改。没有依据的细节保留待核实标记。
- 用户要先看一小段时，提供原文与改写对照；用户认可并要求全文修改后，连续完成指定范围，保存到约定文件，避免每段重复询问。

## 二、段落改写方法

先辨明这一段的中心意思和它在章节中的作用，再重新组织句子。

1. **保留术语和事实。** 专业名称、型号、接口、参数、单位、研究对象和结果数值保持准确。可重写解释，不能为追求差异替换概念或改变条件。
2. **重点检查首尾句。** 开头引出本段问题，结尾形成结论或衔接下文。需要改写时优先调整首尾，但已获用户逐字认可的段落按其要求保留。
3. **改变句子结构。** 可先说使用情境，再说方法；或将长句拆分、将关系紧密的短句合并。主动句、状语位置和叙述角度的调整应让谁做什么、在何种条件下产生何种结果更明确。
4. **按语境换词。** 近义词替换需符合搭配和概念含义。不要把增强、提高、完善等词机械互换，也不要为了显得学术而堆叠抽象名词。
5. **调整顺序并补足说明。** 只有逻辑允许时才调整并列项或叙述顺序。新增解释必须有资料或实现依据，不得擅自扩大分类、功能、效果或研究范围。
6. **自然衔接。** 因果、转折或补充关系不明显时，可用简短衔接语。避免逐句堆砌首先、其次、此外，也不按检测传言一律删除连接词。
7. **减少非必要引号。** 普通强调和自造标签改用直接表达；直接引语、需要逐字保留的命令词条及按规范标注的内容，保留必要引号与来源。改成间接转述后仍保留相应引用。

十句话改七句可作为充分检查段落的提醒，不作为硬性比例。不得为了凑改动数量改坏准确、通顺且必要的句子。段落可以重组，但不能只改开头几个词就声称完成全文改写。

## 三、全文衔接与避免重复

- 保留用户要求的章节结构和必要内容。通常由绪论说明背景与研究范围，总体方案说明模块关系，硬件章解释连接，软件章解释流程，测试章提供证据，结论归纳工作；具体服从学校模板和现有结构。
- 同一功能在不同章节出现时，各自回答不同问题。完整动作列表、参数表或流程在适合的位置集中展开，其他位置简述或引用章节，避免重复粘贴。
- 精简重复表达不等于删除原系统功能。合并前确认独有信息有明确去处，特别检查基础硬件、既有软件和新增工作的衔接。
- 保持必要信息与论证完整，字数通常与原稿接近；解释不足可补充，空泛重复可精简。不用凑字数，也不为了少重复而大幅缩写。用户有明确字数要求时据此检查。
- 改写研究现状时保持作者、研究对象、方法、结论及引用编号的对应关系。引文紧跟它支持的论述，避免被误读为对本文新增功能的证明。

## 四、反防御性写作与适度表达

- 让问题、方法、实现和证据形成主线，明确说明有依据的工作价值。对本科工程论文，重点可放在功能衔接、实现方法和实际任务，不必包装成领先算法或原创理论。
- 减少无关的自我否定、反复免责和开发日志式描述。重要边界在相关位置说明一次，后文按需引用；不把每段都写成风险清单。
- 反防御性写作不代表隐瞒失败、负面结果或重要限制。实测缺失仍标待补，软件构建与逻辑测试不能写成整机实物验收。
- 比较范围应与研究目标匹配，不能为强化优势删除不利但相关的结果。面对不占优的数据，准确解释条件与取舍，不使用没有证据的领先、可靠或显著提升等结论。
- 摘要和引言尽早交代具体问题与本文工作，结论根据已有结果总结。没有实测支撑时，按设计和实现的证据范围表述。
- 避免过度修改：不擅自更换题目、扩展系统、重排全部目录或添加复杂理论；用户要求重构时，再处理相应范围。

## 五、小范围试改与检测反馈

- 用户要求试改时，选择一个内容完整的段落，保留修改前版本供对比；已经认可风格并要求全文修改时，沿用样段标准直接推进。
- 人工检查先看意思是否准确、语句是否通顺、引用是否保留、与上下文是否重复。检测分数不能代替这些判断。
- 如用户提供重复率或AIGC报告，结合报告定位具体段落，再检查表达与来源；不要仅凭报告认定作者身份或内容质量。
- 重复率与AIGC检测是不同指标。不得承诺改写后两者必然同时降低或达到5%等数值；没有实际检测就明确未检测，不模拟报告或虚构效果。
- 修改授权不自动包含上传论文、购买检测或付款。用户明确要求外部检测时，再确认具体渠道、提交范围及费用授权；价格和服务条件需按当时实际信息核实。

## 六、保存与交付

全文重写前，在用户约定位置保留可恢复的原稿。修改完成后回读文件，核对章节、表格、引用、术语、关键数值和待补标记，并通读章节连接处。格式检查只说明文档完整性，不等同于查重、AIGC检测或实物测试。

按用户要求交付对照或最终稿，说明实际保存路径及必要的未完成项。无需反复展示修改过程；没有进行检测时，不宣称已经降低检测分数。
