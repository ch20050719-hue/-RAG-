# 智能家居环境监测、模式控制与智能门锁改造方案

> 本文档已按版本三重新整理。功能与器件事实以 [智能家电版本三功能与硬件规格](智能家电版本三功能与硬件规格.md) 为准；窗户和光照不属于当前实现，normal/sleep/away 作为场景预设保留。

## 1. 需求范围

系统检测温度、湿度、烟雾、火焰和有人状态，并在 OLED 上显示读数、设备状态与报警状态。用户可以通过按键或 APP 手动控制 LED、风扇、舵机门锁和喷淋水泵模拟器，也可以切换到自动模式执行固定阈值联动。

系统支持密码、IC 卡和 APP 三种开锁入口；ESP8266 通过 Wi-Fi 接入机智云，APP 查看传感器数据并远程控制。所有硬件仅用于低压桌面原型。

## 2. 模式定义

本项目只保留 `manual` 和 `automatic` 两种设备主控制模式：

| 模式 | 明确定义 |
|---|---|
| 手动模式 | 按键或 APP 发出明确命令时控制设备；环境读数展示、记录和报警仍可用，但不自动改变执行器 |
| 自动模式 | 在传感器数据有效且设备在线时，根据阈值规则控制固定执行器；不会隐式执行门锁认证或开锁 |

正常、睡眠、离家保留为固定场景预设，不是手动/自动主控制模式。正常不改变设备状态；睡眠关闭 LED 并尝试反锁；离家关闭 LED/风扇并尝试锁门。它们必须通过固定场景工具/API 执行，不能作为隐藏别名绕过安全校验。

场景人工工具矩阵由后端强制执行：

| 场景 | 允许人工控制 | 禁止人工控制 |
|---|---|---|
| 正常 | LED、风扇、水泵、蜂鸣器、阈值、手动/自动模式、门锁 | 无（仍须经过各自安全入口） |
| 睡眠 | LED、风扇、蜂鸣器、门锁 | 水泵、阈值、手动/自动模式 |
| 离家 | 水泵、蜂鸣器、门锁 | LED、风扇、阈值、手动/自动模式 |

三个场景都保留环境读取、设备状态查询、自动安全联动和场景切换。密码、IC 卡、APP 开锁在所有场景可用，但仍必须先通过认证，再进入门锁专用命令链路。

## 3. 领域模型

### 3.1 传感器

| 标识 | 数据 | 单位/范围 |
|---|---|---|
| `room_temp` | 温度 | °C，按模拟器量程校验 |
| `room_humidity` | 湿度 | %，按模拟器量程校验 |
| `room_smoke` | 烟雾浓度 | raw/实验值 |
| `room_flame` | 火焰状态 | 0/1 |
| `room_presence` | 有人状态 | 0/1 |

阈值只允许 `temperature_max`、`humidity_max`、`smoke_max`。火焰和有人采用状态判定，不开放任意阈值寄存器。

### 3.2 执行器

| 标识 | 类型 | 作用 |
|---|---|---|
| `desk_light` | LED/light | 手动照明；自动模式有人时开启 |
| `desk_fan` | FAN | 手动通风；温度或烟雾超上限时开启 |
| `sprinkler_pump` | WATER_PUMP | 火焰检测时模拟喷淋 |
| `alarm_buzzer` | BUZZER | 温度、烟雾或火焰报警 |
| `door_lock` | DOOR_LOCK | 舵机门锁专用状态机 |

水泵、蜂鸣器和门锁不能通过通用 `set_device_state` 或任意底层控制绕过专用安全入口。

## 4. 自动规则

自动模式、数据有效且设备在线时：

1. 温度高于 `temperature_max`：开启风扇和蜂鸣器；
2. 烟雾高于 `smoke_max`：开启风扇和蜂鸣器；
3. 火焰状态为 1：开启喷淋水泵和蜂鸣器；
4. 有人状态为 1：开启 LED；
5. 湿度超过 `humidity_max`：生成报警和记录，当前不自动启动执行器；
6. 手动模式下不执行上述自动设备动作。

## 5. 开锁安全链路

密码、IC 卡和 APP 都是认证来源，不是普通设备状态值。认证成功后，必须由门锁服务创建带 `request_id` 和过期时间的专用命令，再经过门锁在线、门状态、锁舌/反锁状态和 ack 校验。认证失败、房门状态不满足或命令过期时，系统拒绝操作并返回原因。

模型、前端和 APP 不得直接提交 GPIO、舵机角度、Topic 或机智云数据点。舵机角度、密码键盘协议和 IC 卡 UID 白名单必须在硬件联调阶段配置并审计。

## 6. API 与工具

API 前缀为 `/api/v1/home`，主要接口：

| 接口 | 用途 |
|---|---|
| `GET /devices` | 查询固定设备和在线状态 |
| `POST /devices/{id}/state` | 仅控制 LED/风扇等普通开关 |
| `POST /pump/state` | 控制喷淋水泵 |
| `POST /buzzer/state` | 控制报警蜂鸣器 |
| `GET/POST /automation-mode` | 查询或切换手动/自动模式 |
| `GET/POST /scenarios` | 查询或执行 normal/sleep/away 场景预设 |
| `GET/POST /thresholds` | 查询或调整合法阈值 |
| `GET /environment` | 查询五类传感器数据 |
| `/door/*`、`/lock/*` | 门锁专用开门、关门、锁定、解锁和反锁操作 |

Agent 只能调用 `device_tools.py` 中的固定工具；不存在窗户或光照工具，场景预设只能通过 `run_home_scenario` 执行。
