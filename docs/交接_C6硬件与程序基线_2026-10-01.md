## 4. 当前工作副本与原版的区别

工作副本已有 MG90S 门锁控制、语音帧校验和命令队列、窗户非阻塞步进、传感器异常处理、机智云门控与场景协议等修改。具体历史见根目录 `changelog.md` 和既有联调文档。

硬件资源方面：MG90S 驱动使用 PA0 / TIM2_CH1；原来使用 TIM2 的应用定时任务改为 TIM1。原版主要 GPIO 未迁移。因此，不应表述为“与原版硬件相关代码完全相同”，也不能据此断言实物接线被修改。

本次任务仅整理交接，没有新增固件功能、修改工程配置、编译或烧录。

## 5. 关键技术与引脚

使用 STM32 标准外设库、Keil 工程、串口语音输入及机智云 MCU SDK。

| 功能 | 原版及工作副本现有分配 |
|---|---|
| DHT11 | PB3 |
| OLED | SCL：PB1；SDA：PB0 |
| 四个按键 | PB6、PB7、PB8、PB9 |
| 灯、风扇输出 | PB12、PB13 |
| 步进电机 | PA15、PA12、PA11、PA8 |
| 蜂鸣器 | PB5 |
| 语音串口 | USART1，PA9 / PA10，9600 波特率 |
| 机智云串口 | USART2，PA2 / PA3，9600 波特率 |
| 门锁舵机（工作副本新增驱动） | PA0 / TIM2_CH1 |

以上为源码定义；实际接线、供电和机械行程仍以已确认的实物为准。
