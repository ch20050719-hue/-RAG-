# 变更记录

## 2026-10-11 STM32 室内环境查询

- 新增周期遥测接收及非阻塞环境 MCP 工具；无效或超过 3000ms 的读数返回 null，不新增自动控制。
- 控制协议 185、UART/工具回调 77、环境互通 104、超时 47、动画 18 项检查通过。标准重新配置受网络核对阻塞，复用既有 128×160 参数重编译、链接与合并成功；实物待验收。见 docs/STM32环境查询.md。


## 2026-10-10

- 从本地小智源码建立独立 STM32 控制应用。
- 新增 bread-compact-stm32-lcd 板型，以真实 STM32 MCP 工具替换该板型的示例灯。
- 支持灯、风扇、窗户、门，以及手动、自动、睡眠、离家模式。
- 串口队列异步发送，参数白名单校验，返回入队状态；没有设备执行 ACK。
- 验证结果与实物限制见 docs/STM32控制接入.md。
