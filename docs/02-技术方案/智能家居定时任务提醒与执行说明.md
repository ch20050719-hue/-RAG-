# 智能家居定时任务提醒与执行说明

## 1. 当前范围

定时任务只用于设备状态检查和固定设备控制，例如定时开启/关闭 LED 或风扇。版本三不再创建或执行 normal/sleep/away 等旧场景任务；旧数据库记录必须迁移、停用或人工清理后再启用调度。

提醒、截止时间、重复规则和通知机制沿用现有调度器，但设备操作仍必须经过 `DeviceService` 的注册、类型、在线、过期和幂等校验。

## 2. 任务参数

```json
{
  "device_id": "desk_fan",
  "state": "on",
  "_schedule": {
    "reminder_enabled": true,
    "reminder_before_minutes": 10,
    "deadline": "2026-09-20T12:30:00+00:00",
    "repeat_until": null,
    "notification_channels": ["in_app"]
  }
}
```

水泵、蜂鸣器和门锁不应通过通用定时开关任务控制；需要新增专用、带审计的业务任务入口后才能调度。自动环境联动由 `automatic` 模式和环境监测服务触发，不属于定时场景。

## 3. 执行与提醒

- 调度器按分钟检查提醒和截止时间；同一周期只发送一次提醒；
- 到点后进入执行队列，调用统一设备服务并记录结果；
- 一次性任务成功后自动禁用，重复任务计算下一次时间；
- 到达截止时间后标记 `expired`、禁用任务并发送高优先级通知；
- 暂停期间不执行、不提醒，恢复后继续按下一次时间计算。

## 4. 校验与安全

- 执行时间必须存在，提醒时间必须早于执行时间；
- 截止时间和重复结束时间不能早于首次执行时间；
- 只允许 `in_app` 通知渠道；
- 不接受任意 GPIO、MQTT Topic、机智云数据点或底层动作；
- 旧 `home_scenario` 类型仅作数据兼容标识，不得作为版本三新任务入口。

## 5. 验证

调度器时间相关单元测试已通过；默认适配器为 `simulated`，不会因本地定时任务误控制真实设备。ESP8266、STM32、机智云和真实执行器联调另行记录。
