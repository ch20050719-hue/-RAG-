# 智能对话无输出问题修复说明

## 1. 问题现象

进入多智能体协作页面后，用户消息可以显示，但 AI 消息区域为空，页面长时间停留在“思考中”或“处理中”。浏览器网络面板中的流式接口可能返回 HTTP 200，但没有可显示的最终文本。

## 2. 根因

本次问题由多个因素叠加造成：

1. OpenAI 兼容模型网关请求继承了系统环境中的失效代理 `127.0.0.1:9`，模型和 Embedding 请求无法建立连接；
2. OpenAI 对话适配器没有读取 `OPENAI_VERIFY_SSL`，自定义网关证书异常时无法按本地开发配置运行；
3. 多智能体编排器和质量审核调用 `llm_adapter.agenerate()`，但 `OpenAIAdapter` 没有实现该兼容方法；
4. Windows 默认 GBK 控制台编码无法输出意图路由智能体初始化时的 Emoji，导致流式请求在初始化阶段中断；
5. 前端保留了已经创建但内容为空的 AI 消息，因此后端异常时页面看起来像“没有输出”。

## 3. 修复内容

### 3.1 OpenAI 对话适配器

文件：`financial_rag/rag_backend/app/agent_framework/llm/openai_adapter.py`

- 增加 `agenerate(prompts, temperature, max_tokens, **kwargs)`；
- 增加 `OPENAI_VERIFY_SSL` 配置读取；
- 增加 `OPENAI_TRUST_ENV` 配置读取；
- 默认不继承系统代理，避免失效代理影响模型调用。

### 3.2 OpenAI Embedding 适配器

文件：`financial_rag/rag_backend/app/services/adapters/openai_adapter.py`

- 使用显式 `httpx.Client`；
- 同样应用 SSL 校验和系统代理配置；
- 避免 RAG 查询向量化请求被代理或证书错误阻断。

### 3.3 配置项

文件：`financial_rag/rag_backend/app/core/config.py`

新增：

```text
OPENAI_VERIFY_SSL=true
OPENAI_TRUST_ENV=false
```

生产环境应保持 `OPENAI_VERIFY_SSL=true`，并为自定义网关配置正确的 CA 证书。仅在本地开发网关证书不受信任且风险可接受时，临时使用 `OPENAI_VERIFY_SSL=false`。

### 3.4 Windows 启动环境

本地启动后端时设置 UTF-8 输出环境：

```powershell
$env:PYTHONIOENCODING="utf-8"
$env:PYTHONUTF8="1"
$env:HOME_DEVICE_ADAPTER="simulated"
$env:HOME_DOMAIN_MODE="1"
$env:OPENAI_TRUST_ENV="false"

cd financial_rag/rag_backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

如果当前模型网关证书仍未被本机信任，本地开发进程还需要：

```powershell
$env:OPENAI_VERIFY_SSL="false"
```

不要把 API Key 写入启动命令或提交到 Git；通过 `.env` 或安全的环境变量注入。

### 3.5 对话入口合并

原侧边栏同时显示“智能对话”和“多智能体协作”，实际面向用户的能力重复。现已将根路径 `/` 统一指向智能家居多智能体对话页面，仅保留一个“智能对话”入口；旧地址 `/multi-agent` 保留为兼容跳转，不影响已有书签或后台任务链接。

> 历史说明：以上记录描述的是 2026-09-17 的 MultiAgent 入口合并，不是当前完整控制架构。当前默认智能家居自然语言控制应采用 Marvis 风格的主 Agent + 专业子 Agent；知识/RAG 和设备控制子 Agent 内部采用 ReAct/工具循环。请以 [智能家居当前架构决策记录](智能家居当前架构决策记录.md) 为准。

## 5. 安全注意事项

- 本地开发默认使用 `HOME_DEVICE_ADAPTER=simulated`，不会连接真实家居设备；
- `OPENAI_VERIFY_SSL=false` 只能作为本地临时兼容措施，生产环境应恢复为 `true`；
- 本次诊断过程中曾有 API Key 意外进入工具日志，相关 Key 必须立即吊销并轮换，随后更新本地 `.env`；
- 不要在提交、日志、截图或文档中记录完整 API Key、Redis 密码或数据库密码。
