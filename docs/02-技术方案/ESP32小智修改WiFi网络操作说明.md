# ESP32 小智修改 WiFi 网络操作说明

适用于 ESP32-S3 小智设备及当前 `bread-compact-stm32-lcd` 固件。修改设备连接的 Wi-Fi，通过启动期间的 BOOT 按键进入配网模式完成，无需重新编译或烧录。

## 修改网络步骤

1. 保持设备供电，准备新网络的名称和密码。选择有互联网连接的 2.4 GHz Wi-Fi。
2. 按一下板上的 **RST**，然后松开，设备开始重新启动。
3. 随即在启动期间**单击 BOOT 并松开**，等待设备显示或播报“配网模式”。不要按住 BOOT 再按 RST，否则可能进入下载模式。
4. 在手机的 Wi-Fi 设置中连接设备的配网热点。当前设备日志中的热点名称为 `Xiaozhi-DD49`，实际以设备显示、播报或串口日志为准。
5. 配网终端提示“无互联网连接”时，选择继续连接小智热点，避免自动切回其他 Wi-Fi。必要时暂时关闭该终端的移动数据、VPN 或代理；如果另一部手机正提供目标热点，保持它的移动数据和热点开启。
6. 在浏览器地址栏完整输入 `http://192.168.4.1`，打开配网页面。使用 HTTP，不要改成 HTTPS。
7. 在配网页面选择新的 Wi-Fi，输入密码，按页面提示保存或连接。
8. 等待设备连接新网络。配网热点断开后，手机可恢复连接正常使用的网络。

不要把 Wi-Fi 密码写入项目文档、截图或公开日志。

## 判断连接成功

设备连接路由器后，串口日志会出现以下信息；网络名称和 IP 地址以实际输出为准：

```text
WifiBoard: Connected to WiFi: <新网络名称>
WifiStation: Got IP: <路由器分配的地址>
Application: Network connected
```

小智服务连接和激活完成后，还可看到：

```text
MQTT: Connected to endpoint
Application: Activation done
StateMachine: State: activating -> idle
```

前一组表示 Wi-Fi 已连接，后一组表示小智服务已连接并进入待机。可说“你好小智”测试普通对话；联网成功不等于 STM32 控制链路已完成实物验收。

需要查看日志时，在已激活的 ESP-IDF PowerShell 中执行：

```powershell
cd F:\esp\v6.0.2\esp-idf-2\xiaozhi-stm32
idf.py -p COM10 monitor
```

`COM10` 是用户最新确认的烧录端口，`COM11` 属于历史排查记录。重新插拔后如端口变化，应使用当前设备端口。已有串口监视窗口时直接使用，避免同时打开同一个端口。退出监视按 **Ctrl + ]**。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 重启后又自动连接旧网络 | 错过了启动期间的 BOOT 按键时机。重新执行“按 RST 并松开，随即单击 BOOT”。 |
| 待机时按 BOOT 没有进入配网 | 当前固件在待机时单击 BOOT 用于切换对话状态。需要在启动期间单击。 |
| 找不到设备热点 | 检查设备是否已进入配网模式，确认热点名称；串口应出现 `Access Point started with SSID`。 |
| 打开网页提示 `ERR_EMPTY_RESPONSE` | 确认打开网页的手机或电脑仍连接设备热点，地址为 `http://192.168.4.1`；暂时关闭代理或 VPN。若仍失败，检查日志中是否有 `Web server started`，以及设备是否重启。 |
| 联网后打不开 `192.168.4.1` | 此地址属于配网模式。连接路由器后的正常运行模式不提供该配网入口，需要再次进入配网模式才能修改网络。 |
| 新网络连接失败 | 核对网络名称、密码和 2.4 GHz 频段；结合串口日志区分 Wi-Fi 连接失败与小智服务连接失败。 |

## 当前手机热点连接失败

2026-10-11 用户反馈配网页面报 `Failed to connect to the Access Point`，并确认目标网络为手机热点。手机是安卓还是 iPhone、频段与断连 reason 尚未提供；更换新网络没有成功验证。此前路由器联网与 MQTT 激活日志不能用来证明新热点已连接。

代码来源为应用 `managed_components/78__esp-wifi-connect/wifi_configuration_ap.cc`：配网处理调用 `ConnectToWifi()`，失败时返回此通用错误，成功后才保存这次提交的 SSID。失败可能是关联失败或等待连接超时，页面没有给出准确原因；不能据此认定是密码错误，也不能当成 MQTT 或模型服务故障。该依赖源码仅用于核对，不修改。

下一步先确认手机型号：安卓检查热点的 2.4GHz 频段设置，具体菜单随厂商变化；支持该选项的 iPhone 可尝试“设置 → 个人热点 → 最大兼容性”。Apple 官方说明，iPhone 12 及后续机型的最大兼容性将热点限制为 2.4GHz 并使用 WPA2，见[Apple 无线局域网安全说明](https://support.apple.com/zh-cn/guide/security/secfd166f620/web)。这是排查建议，尚未确认能解决用户本次问题。

保持热点手机的移动数据与热点开启，核对名称和密码，尽量使用另一部手机或电脑操作小智配网页面。如果重试仍失败，保存本次 `Connecting`、`Attempt ... failed/timed out`、断连 reason、`Got IP` 附近日志；先移除密码和凭据，再用于排查。得到 IP 后再检查 MQTT 和激活状态。

## 按键逻辑与适用范围

当前应用路径：`F:\esp\v6.0.2\esp-idf-2\xiaozhi-stm32`。

按键逻辑位于 `main/boards/bread-compact-stm32-lcd/compact_wifi_board_lcd.cc` 的 `InitializeButtons()`：启动状态下单击 BOOT 调用 `EnterWifiConfigMode()`，其他状态下单击调用 `ToggleChatState()`。

本说明于 2026-10-11 根据当前源码和设备日志核对。用户提供的日志已显示配网热点与网页服务启动，以及后续连接 Wi-Fi、MQTT 和激活完成；更换新网络的完整操作仍需实际执行确认。
