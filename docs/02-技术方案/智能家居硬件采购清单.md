# 智能家居毕业设计硬件采购清单

## 一、推荐方案

本项目采用：

> **ESP32 + 温湿度检测 + 光照检测 + 人体检测 + LED 灯 + 5V 小风扇**

硬件负责感知环境和执行动作；大模型、RAG、多 Agent 和 MQTT 运行在电脑后端。

## 三、建议购买版本

### 3.1 控制器

```text
ESP32 DevKit V1，带 USB 接口
```

选择带 USB 接口的开发板，方便使用 Arduino IDE 烧录程序。

### 3.2 温湿度传感器

优先选择：

```text
DHT22
```

DHT11 也能使用，但精度和测量范围较低。预算有限时可以用 DHT11 替代。

### 3.3 风扇控制

优先使用：

```text
5V USB 小风扇 + MOSFET 模块
```

也可以使用 1 路继电器模块。风扇必须使用低压 5V 设备，不要接 220V 市电。

## 五、第一阶段不要购买

以下设备不是项目第一版的必要内容：

- 树莓派；
- STM32 开发板；
- 220V 家用电器；
- 智能空调红外控制器；
- 多种复杂传感器；
- 机器人底盘；
- 摄像头云台；
- 大功率电机和电源模块。

原因是本项目的重点是：

```text
大模型 + RAG + 多 Agent + MQTT + 设备执行闭环
```

不是制作复杂的硬件系统。

## 九、安全注意事项

1. 只使用 5V USB 小风扇和 LED 做演示；
2. 不要把面包板电路接入 220V 市电；
3. 继电器模块即使支持高压，也不要在本科演示中控制家用电器；
4. ESP32、传感器和执行器要共地；
5. 风扇启动电流较大时，使用独立 5V 供电，并确保共地；
6. 所有设备控制先经过后端安全规则，不让大模型直接生成任意硬件指令。
