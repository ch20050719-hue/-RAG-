# 智能家居项目文档

当前文档只描述智能家居模块。RAG 检索、Agent 编排、多轮会话、认证、租户隔离和审计属于保留的通用基座；设备控制、安全规则、MQTT 和 ESP32 属于当前业务实现。

## 文档约定

1. 新文档围绕智能家居设备、环境、场景、控制安全和联调展开；
2. 设备控制必须以 `app/home_automation/device_tools.py` 为唯一工具入口；
3. 文档中的 MQTT 示例不得暴露生产密码、任意 Topic 或任意 GPIO；
4. ESP32 仅用于低压 LED 与 5V 风扇桌面演示，禁止接入 220V 市电；
5. 验证至少记录后端家居单元测试、`git diff --check` 和前端 `npm run build`。
