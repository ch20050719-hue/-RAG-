# 智能家居项目精简与保留清单

## 1. 精简原则

项目只围绕一条可演示主线：用户自然语言 → 大模型意图理解 → 结构化参数 → 固定设备工具 → 设备注册/类型/在线/命令状态/TTL 校验 → 安全规则 → 模拟或受控 MQTT 适配器执行 → 状态与执行回执。

与其他业务领域相关的入口、配置、提示词、知识种子和页面不属于当前产品范围，不再加入运行链路或文档导航。

## 2. 必须保留

| 能力 | 保留原因 |
|---|---|
| 大模型意图理解 | 将自然语言转换为受控的设备操作意图和参数 |
| Agent 编排 | 支撑意图识别、环境分析和固定工具调度 |
| 多轮会话与 SSE | 支撑连续控制对话和过程展示 |
| 认证、权限、租户隔离、审计 | 防止未授权设备操作 |
| 设备注册表与设备服务 | 形成可测试的设备抽象 |
| 固定设备工具 | 限制模型只能执行允许的动作 |
| 安全规则 | 拦截离线、非法、过期和重复控制 |
| 模拟适配器 | 无硬件时完成完整演示和自动化测试 |
| 机智云/协议适配器 | 连接 ESP8266-01S 与 STM32F103C8T6 版本三硬件 |
| STM32 版本三低压原型 | 验证传感、显示、控制和通信闭环 |

## 3. 当前版本三设备范围

- 执行器：低压 LED、5V 风扇、喷淋水泵模拟器、有源蜂鸣器、舵机锁门装置；
- 传感器：温度、湿度、烟雾、火焰、有人状态；
- 输出与交互：OLED、按键和机智云 APP；
- 控制状态：LED/风扇/水泵/蜂鸣器开关、门锁状态、手动/自动模式和阈值；
- 硬件边界：仅低压桌面原型，禁止接入 220V 市电。

## 4. 明确不纳入首版

- 任意品牌协议和任意 Topic/GPIO 控制；
- 真实住宅门锁、220V 家电、燃气、电热和摄像头等高风险设备；
- 需要长期在线的生产 Broker、远程公网控制和商业化运维；
- 未经验证的性能指标、硬件稳定性指标和生产 SLA。

## 5. 清理检查

1. 默认路由、菜单和固定配置只出现智能家居能力；
2. Agent 工具列表不包含任意设备命令；
3. MQTT 连接信息通过环境变量提供，仓库不保存密码；
4. 删除或停用的内容不再被入口、导入、测试和文档导航引用；
5. 修改后执行后端家居与安全测试、`compileall`、前端构建和 `git diff --check`。
