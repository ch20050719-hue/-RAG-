## 文件使用

每张图提供2000×2000正方形PNG和同尺寸矢量SVG。节点采用分行、分列布局，文字与图形保持原比例。双击[图册.html](图册.html)可查看全部配图。图下说明与源码依据供写作核对，论文图题按实际章节统一编号。

`.mmd`保留可编辑的流程逻辑；SVG保留当前方形布局，可用矢量编辑器修改。`square-layouts.json`记录方形图的节点布局；Mermaid默认自动排版不保证正方形，重新导出时需同时调整布局。

## 研究与验收状态

软件实现、历史回归和工程编译记录见项目变更日志及交接文档。本次仅核对源码与整理配图，没有重新运行固件回归、编译或烧录。2026-10-28手机协议修复后，最新STM32固件仍待烧录及APP端到端实物验收；新起床词库完整语音固件也待平台生成和烧录。研究技术路线中的实物测试与结论整理为后续工作。

光照使用相对读数，烟雾使用未标定ADC值。现有OLED仍有Lux文字，相关显示修正尚待实施。机智云物模型没有独立环境有效位，采样失败时APP字段可能保留旧值；小智查询另行执行有效性及3000 ms时效检查。门窗目标和软件步数不能作为实物到位证据。

## 12_睡眠离家与起床场景

场景从专用入口设置手动模式与状态记录，避免普通自动退出清理覆盖场景。睡眠、离家本身保持蜂鸣器输出；起床明确关闭蜂鸣器。窗户和门均为下发目标。
