## 功能与边界

用户询问室内环境时，小智通过 `self.stm32.get_environment` 读取 STM32 的温度、湿度、相对光照和烟雾 ADC 数据，并据此组织语音回答。工具描述要求每次回答环境问题先读取数据；实际云端工具调用和回答内容须在设备上验收。

环境查询不下发控制命令、不切换手动/自动模式，不增加主动提醒或无人值守自动控制。温湿度可用于一般环境描述，不能把固件原有自动控制阈值当作舒适度标准。光照尚未实物标定，不能输出准确 lux 或按未经标定的阈值断言明暗；这些未标定的环境指标不能判断空气安全或是否有人。

## 成熟方案调研

- 复用已有小智设备端 MCP 工具注册、现有设备连接及 STM32 传感器采样，不增加服务端或第三方依赖。[小智官方 MCP 文档](https://github.com/78/xiaozhi-esp32/blob/main/docs/mcp-usage_zh.md)
- ESP32 在独立任务中通过 UART 驱动接收，MCP 主线程只读缓存，避免等待串口影响对话。[Espressif UART 官方示例](https://github.com/espressif/esp-idf/blob/master/examples/peripherals/uart/uart_events/main/uart_events_example_main.c)
- STM32 复用标准库 TXE 中断发送，主循环不忙等。18 字节遥测帧是现有两端应用之间的新增约定，不改变机智云协议。[STM32F1 RM0008](https://www.st.com/resource/en/reference_manual/cd00171190.pdf)

## 数据路径

STM32 每秒执行已有 `Menu_UpdateSensors`，采样后将快照交给 USART3 的单帧发送缓冲。TXE 中断逐字节发送；若缓冲仍忙，跳过该次上报。接收控制指令的 RXNE 分支继续独立工作。

接线沿用 STM32 PB10 TX → ESP32 IO18 RX、ESP32 IO17 TX → STM32 PB11 RX，共地，9600 8N1。板型保持 `bread-compact-stm32-lcd`，屏幕保持 128×160，不修改只读原版和 ESP-IDF SDK。

ESP32 接收任务解析帧并在临界区更新缓存。查询工具在临界区复制缓存，离开临界区后序列化；回调不执行串口读写，不等待新采样。

## 遥测协议

当前 v2 固定 20 字节，整数小端；v1 为历史 18 字节格式，新 ESP32 仍可接收：

| 字节索引 | 字段 |
|---|---|
| 0 | 帧头 `F4` |
| 1 | 遥测类型 `08`，原控制帧类型仍为 `06` |
| 2 | 协议版本 `02` |
| 3 | bit0 温湿度有效，bit1 光照与烟雾 ADC 共同有效；其余位为 0 |
| 4、5 | 温度 ℃、湿度 %RH，各 1 字节 |
| 6–7 | `4096 - ADC` 相对光照值 |
| 8–9 | 烟雾 ADC 原始值 |
| 10–13 | STM32 温湿度采样年龄，毫秒 |
| 14–17 | STM32 ADC 采样年龄，毫秒 |
| 18 | 字节 1–17 的 XOR |
| 19 | 帧尾 `FB` |

有有效标志时，温度范围为 0–50℃，湿度 0–100%RH，光照 raw 1–4096、烟雾 ADC 0–4095。烟雾 0 是合法原始值，不等于没有烟雾。无效字段可以携带最后一次读数，但查询结果将其替换为 `null`。单个传感器失效不遮蔽另一传感器的正常数据。

解析器使用最大 20 字节滑窗，按协议版本检查完整的 18/20 字节后缀，检验帧头、类型、版本、有效位、数值范围、校验及帧尾。载荷中的 `F4`、`FB` 不打断帧，损坏或截断后可从后续正确帧恢复。

## 数据有效性

温湿度复用 `DHT11_DataValid`；光照与烟雾复用 `ADC_DataValid`。现有 ADC 有效位同时要求光敏和烟雾通道采集成功，暂不拆分这一保守判断。

有效性同时要求传感器有效标志和数据年龄不超过 3000ms。ESP32 将收到帧后经过的时间累加到 STM32 报告的采样年龄，避免断开后仍把旧数据当作实时值。加法溢出时饱和为最大年龄。

未收到帧时 `received=false`；收到过帧但过期时仍可 `received=true`，对应有效位为 false、读数为 null。`received` 不表示当前在线。失效读数不能当作 0℃、0%RH 或全黑。

返回字段包括 `temperature_c`、`humidity_percent_rh`、`light_raw`、`smoke_raw`、`smoke_valid`、`smoke_unit=adc_raw_uncalibrated`、`dht_valid`、`adc_valid`、两项 `age_ms`、`max_age_ms` 和 `light_unit=relative_raw_uncalibrated`。

5. 断开 STM32 → ESP32 的 TX 数据线，等待超过 3 秒再询问，确认不再报告旧实时读数；恢复后约一个采样周期内应重新收到数据。
