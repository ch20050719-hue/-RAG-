## 文档约定

1. 新文档围绕智能家居设备、环境、场景、控制安全和联调展开；
2. 当前设备控制以 STM32 固件、已确认硬件和现有机智云链路为准，不新增 Python 控制后端；
3. 文档中的 MQTT 示例不得暴露生产密码、任意 Topic 或任意 GPIO；
4. 当前工作副本以用户 2026-10-10 确认的 STM32F103C8T6 配置为准；C6 为只读原版及历史运行记录。仅用于低压桌面原型，LED、5V 风扇、28BYJ 和舵机锁门装置禁止接入 220V 市电；
5. STM32 固件改动记录相关 C 逻辑测试和 Keil 编译结果；实物联调单独记录板卡、固件和接线版本。STM32-only 改动不依赖 Python 后端测试或前端构建。
